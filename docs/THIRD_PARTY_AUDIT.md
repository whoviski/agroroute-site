# Аудит сторонних компонентов

Дата сверки с кодом: 9 ноября 2026 г.  
Проект: статический сайт AgroRoute (GitHub Pages). Сборки, `package.json` и зависимостей pip/npm в репозитории нет.

Проверены HTML, CSS и JS: внешние `script`, `link`, `iframe`, шрифты, аналитика, карты, видео, `fetch`, cookie, `localStorage`, `sessionStorage`, формы и журналирование.

| Компонент | Что это | Что получает | Куда (страна) | Нужен ли | Решение |
| --- | --- | --- | --- | --- | --- |
| Системные шрифты (`system-ui` и запасные из CSS) | Шрифт на устройстве | Ничего не отправляет | Не применяется | Да, для текста | Оставлены. Google Fonts и CDN шрифтов нет |
| Файлы `img/` | Свои изображения | Только обычный HTTP-запрос файла у хостинга | GitHub Pages, США | Да, для содержания страниц | Оставлены, раздаются вместе с сайтом |
| `style.css`, `app.js`, `consent.js` | Свои скрипты и стили | Не отправляют персональные данные. `app.js` не пишет cookie и storage. `consent.js` после выбора пишет один ключ localStorage | Браузер посетителя; файл скрипта отдаёт GitHub Pages, США | Да | Оставлены. Необязательные скрипты не загружаются ни до, ни после согласия, потому что их нет |
| `agroroute_cookie_consent` | Ключ localStorage | Ничего по сети. JSON: `v`, `necessary`, `analytics`, `marketing` | Только браузер | Да, чтобы помнить выбор | Добавлен. Строго необходимый. До нажатия кнопки в полосе не создаётся |
| GitHub Pages | Хостинг статических файлов | IP-адрес, время запроса, URL, user-agent и обычные заголовки — чтобы отдать файл. Код сайта эти журналы не получает | США | Да, иначе сайт не открывается | Оставлен как способ публикации. В политиках указан прямо. Отдельного договора поручения в репозитории нет |
| Аналитика, реклама, карты, видео, CDN | Нет в коде | Нет | Нет | Нет | Не подключались. Согласие «Принять все» ничего дополнительно не загружает |
| npm / pip | Нет манифестов и зависимостей | Нет обращений при сборке: сборки нет | Нет | Нет | Не используются |

Форм, полей пароля и серверных API в этом репозитории нет. Удалять нечего: лишние поля и журналы персональных данных в коде не найдены. Чекбокс согласия на форме не добавлялся, потому что формы нет. Кабинет со снимка «Авторизация» на этом сайте не работает.
