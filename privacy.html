2. Какие данные обрабатываются

Код сайта проверен по состоянию на 9 ноября 2026 г. На сайте нет форм, регистрации, личного кабинета и оплаты. Скрипты сайта не отправляют данные на сервер оператора и не пишут персональные данные в журналы.

  • Сайт не запрашивает фамилию, имя, телефон, паспортные данные, платёжные данные и пароль.
  • Единственная запись, которую создаёт сам сайт, — выбор посетителя по cookie. Она хранится в localStorage браузера под ключом agroroute_cookie_consent и на сервер оператора не передаётся. Состав ключа описан в Политике cookie.
  • Если человек сам пишет на say-maklashov@mail.ru, оператор получает адрес отправителя и текст письма — в том объёме, который человек указал.
  • Сайт собран из статических файлов и публикуется через GitHub Pages. Чтобы отдать страницу, инфраструктура GitHub получает IP-адрес, дату и время запроса, адрес запрошенной страницы и обычные заголовки браузера, включая user-agent. Через код этого репозитория оператор эти журналы не получает.

  • Срок журналов GitHub Pages определяет хостинг, а не этот сайт. Оператор отдельный срок для них не устанавливает.
